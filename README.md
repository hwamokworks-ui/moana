# Moana

영화 "모아나 2"를 소개하는 팬 소개 랜딩 페이지입니다. 예고편 영상, 줄거리, 주요 등장인물(모아나, 마우이, 헤이헤이 & 푸아) 소개 섹션으로 구성되어 있습니다.

## 기술 스택

- 순수 HTML + [Tailwind CSS](https://tailwindcss.com/)(CDN)
- Pretendard 웹폰트, YouTube 임베드
- 별도 빌드 도구 없이 `index.html` 단일 파일로 구성

## 실행 방법

빌드 과정이 필요 없습니다. `index.html`을 브라우저로 열거나 정적 파일 서버로 서빙하면 됩니다.

```bash
npx serve .
```
